# Own the Plot — ferffernanda

Personal-brand website for Fernanda Vales (@ferffernanda): Pilates, health
coaching, astrology & self-discovery, based in Dubai.

Static HTML/CSS. No build step. Hosted on Netlify (with Netlify Forms for the
waitlists and the Honest Check-In).

## Pages
- `index.html` — home
- `schedule.html` — class timetable (306, Vybe, AERA), privates, Sunset & Stars Pilates
- `tools.html` — free tools hub
- `check-in.html` — The Honest Check-In (12-question quiz + email capture)
- `thank-you.html` — form fallback page

## Forms (Netlify)
- `own-the-plot-waitlist`
- `beach-pilates`
- `honest-check-in`

## Deploy
Connected to Netlify. Pushing to `main` auto-deploys.
